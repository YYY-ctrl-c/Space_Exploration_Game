# 太空探索指挥中心 (Space Exploration Command Center)

## 项目简介
这是一个基于 Web 的太空探索指挥模拟管理系统。玩家扮演一名指挥官，通过招募舰员、探索星域、管理货舱物资及进行商业贸易，构建属于自己的星际舰队。系统采用前后端分离架构，旨在提供流畅的交互体验与数据管理能力。

## 技术栈
* **前端 (Frontend)**: Vue 3
* **后端 (Backend)**: Java Servlet
* **数据库 (Database)**: MySQL

## 主要功能
* **用户系统**: 支持指挥官账号登录与身份验证。
* **舰员管理**: 
    * 舰员档案：查看已拥有舰员的详细状态。
    * 疲劳管理：补充能量与物资，维持舰员高效运作。
    * 舰员图鉴：展示所有可招募舰员的图鉴系统，区分稀有度与背景。
* **星域探索**: 支持前往不同星域进行任务，通过探索掉落获取奖励。
* **星际商店**: 指挥官可使用星币购买各类补给物资，确保舰队能源充足。
* **货舱管理**: 实时查看舰队所持有的道具与资源库存。
* **补给舱**：抽奖获得星币和舰员。

## 项目目录结构

### 1. src/
源代码主目录，包含核心开发文件：
* **frontend/**: Vue3 项目源码，负责前端页面渲染与交互逻辑。
* **backend/**: Java Servlet 后端源码，负责业务逻辑处理与接口实现。
* **database/**: 项目所需的 MySQL 数据库 SQL 初始化与表结构脚本。

### 2. 文档/
存放项目的辅助说明资料：
* 包含课程设计文档、系统架构图、界面截图、项目进度记录及相关技术报告。

### 3. README.md
项目说明文档，用于介绍系统概况、目录结构与使用说明（即本文件）。

## 环境配置建议
1. **数据库**: 请确保 MySQL 已安装并导入 `database/` 下的 SQL 脚本。
2. **后端**: 配置 Java 开发环境（JDK 22），部署至 Tomcat 或相关 Servlet 容器。
3. **前端**: 安装 Node.js，在 `frontend/` 目录下运行 `npm install` 与 `npm run dev` 启动开发服务。
